Node label cN = queen tried in column N of that level's row. Under red nodes: col = column conflict, diag = diagonal conflict.

Algorithm (pseudocode)

procedure Solve(row):                         // N = 4
    if row > N:  record solution; return
    for col ← 1 to N:
        if IsSafe(row, col):
            place queen at (row, col)
            Solve(row + 1)                    // recurse
            remove queen from (row, col)      // BACKTRACK
        else:  prune branch  (invalid, red)

function IsSafe(row, col):
    for r ← 1 to row − 1:
        c ← column of the queen in row r
        if c = col or |c − col| = row − r:  return false
    return true

Solve(1)                                      // start

How to read the visualization

  • Level = row. Each level of the tree is one recursive call Solve(row), which places exactly one queen in that row.
  • Branch = choice. Every node is one attempt to put a queen in a column of that row; its parent is the partial placement it extends.
  • Red = invalid. If the square shares a column or diagonal with a queen already placed, the branch is pruned immediately (shown red, with the reason) and nothing below it is explored.
  • Backtracking. When every column of the next row has been tried, the call returns and the queen is removed (the board updates), then the next column of the previous row is tried.
  • Green = solution. Placing the 4th queen safely means all 4 queens are safe. N = 4 has exactly 2 solutions; the search continues until the whole tree is explored.
